# Aramco Prep (unofficial)

A practice site for the Aramco SHL online assessment: Verbal, Inductive and Numerical sections in the real test layout. Made for educational use. Not affiliated with Saudi Aramco or SHL.

Live site: https://q55.github.io/aramco-prep/

- Plain static site served by GitHub Pages.
- Sign-in (Google or email) and saved progress use Firebase Auth and Firestore. See `SETUP.md` and `firestore.rules`.
